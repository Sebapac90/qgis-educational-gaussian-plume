description=Educational Gaussian plume simulations with georeferenced outputs and wind observations.
about=Educational, non-regulatory QGIS plugin implementing the classical steady-state Gaussian plume model over flat terrain.
    Students can select stability A-F, adjust wind speed from its measurement height, use constant, synthetic or CSV wind data, calculate final Briggs plume rise, and create georeferenced raster, isoline, source and wind-rose outputs.
    It does not model terrain effects, gradual plume rise, deposition, building downwash or atmospheric chemistry.
    The interface is available in Spanish and English. It uses NumPy, PyProj and Matplotlib from the QGIS Python environment.
